留声 · 安装说明
================

留声在这台 Mac 上把录音转成文字，并自动标「说话人一 / 说话人二」。
不调用任何云端 AI，录音和文字都不出这台电脑，也只有这台电脑自己能打开
（同一 Wi-Fi 下的手机、其他电脑都连不上——转录记录没有密码保护，这是故意的）。

要求：Apple Silicon 的 Mac（M1 及以后），macOS __MACOS_MIN__ 或更新。
不需要装 Homebrew、Node、ffmpeg——都已经打在包里了。
说话人分离的模型也在包里；它还需要一个小的运行环境（约 50MB），装一次即可，在「终端」里跑：
  python3 -m venv ~/.diar-venv && ~/.diar-venv/bin/pip install "sherpa-onnx>=1.13"
（第一次用 python3 时 macOS 可能提示安装命令行开发者工具，同意即可。）
没有装也能正常用，只是转录不带说话人标注。

安装
----
装新版之前：如果旧版正开着，先打开「活动监视器」，搜 node，结束进程，再往下装——
不然双击打开的还是旧版。

1. 把「留声」拖到旁边的 Applications 文件夹里。

2. 打开「应用程序」，双击「留声」。
   第一次会弹「Apple 无法验证“留声”是否包含可能危害 Mac 安全或泄漏隐私的恶意软件」——
   点「完成」（不要点「移到废纸篓」），然后：
   系统设置 → 隐私与安全性 → 拉到最下面「安全性」一栏 → 「仍要打开」→ 再确认一次「仍要打开」→ 输入密码。
   这一步只做一次（留声没有做苹果开发者签名，所以需要手动放行）。放行后留声会自动打开；没打开就再双击一次。
   （嫌麻烦的话，在「终端」里执行这一句效果相同：xattr -cr /Applications/留声.app）

3. 接着会先弹一个说明框，点「继续」，然后系统会弹框要求输入一次本机登录密码——这是信任留声的
   本地 HTTPS 证书，也只做一次。之后浏览器会自动打开 https://localhost:3443。

日常使用
--------
- 双击「留声」= 打开网页。服务已经在跑的话不会重复启动，只是再开一次网页。
- 把录音拖进网页就开始转：一次拖多个文件、整个文件夹都行，按文件名顺序一个个转。
- 服务会一直在后台跑。想彻底退出：打开「活动监视器」，搜 node，结束进程；或者注销 / 重启。
- 转录记录只保留 24 小时，文字请及时复制出去。
- 「显示说话人 / 纯文字」在结果页右上角切换；说话人编号是声纹自动分的，
  偶尔会把同一个人拆成两个编号，以内容为准。点说话人标签可以改成真名，
  显示和复制出来的都会换成真名。
- 有些英文专有名词 whisper 总认错（比如把 Claude Code 写成 Cloud Code），转录完会按「纠错词表」自动改正。
  词表点网页右上角「纠错词表」就能改，每行「错词 => 正词」，保存后下一次转录就生效。

手机录的音
----------
手机浏览器打不开留声（只有这台 Mac 自己能打开）。用手机自带的「语音备忘录」录，
录好后传到 Mac（隔空投送最方便），再在留声里上传。
Mac 如果弹出「是否允许应用程序“node”接受传入网络连接？」，点「拒绝」，不影响使用。

文件放在哪
----------
- 转录 / 上传数据：~/Library/Application Support/留声/data
- 纠错词表：       ~/Library/Application Support/留声/data/纠错词表.txt
- 证书：           ~/Library/Application Support/留声/certs
- 日志：           ~/Library/Logs/留声/server.log

出了问题
--------
- 打不开、网页一直转：看日志 ~/Library/Logs/留声/server.log。
- 提示「证书安装失败」：重新双击留声，在密码框里输入密码。
- 想彻底重来：先结束 node 进程，删掉整个 ~/Library/Application Support/留声 文件夹，再双击留声
  （会重新要一次密码；纠错词表也会回到默认，自己加过的词要重新加）。
